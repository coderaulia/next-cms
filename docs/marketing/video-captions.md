- **Source:** the caption text matches each post in `tiktok.md` (ID/EN captions, titles and pinned comments). The 5 screen tours were written here, since they had no caption yet.
- **Videos are silent.** Add a sound from the TikTok Commercial Music Library in the app.
- **Rendered** column shows whether the file exists in `output/video/` right now. To render missing ones: `cd video && npm run render -- --skip-existing`.
